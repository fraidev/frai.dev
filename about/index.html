Hi. I’m Felipe Cardozo, or just frai.

Software engineer from Macaé, Rio de Janeiro, Brazil, graduated at Computer Engineering.

I like the lower layers: runtimes, networking, streaming systems and the tooling around them. Most of my work in the last years landed in open source repositories, in Rust, TypeScript, OCaml, Go and Elixir. The pull requests are in contributions, the side quests in projects.

Currently at Cumbuca.

Before that, Deno, InfinyOn and Marigold.

Experience

  • Cumbuca · Software Engineer · May 2026 - present · remote
  • Deno · Software Engineer · Nov 2025 - Mar 2026 · remote
    • Worker debugging over CDP, so Chrome DevTools and VS Code can debug Web Workers.
    • Native source maps support across deno_core and deno_graph.
    • HTTP agent keepAlive connection reuse for Node.js clients such as the AWS SDK, cutting request latency from about 500ms to about 150ms.
    • Fixed a fetch file descriptor leak by moving per-thread HTTP clients to a shared client.
    • A long tail of Node.js child_process compatibility: argument validation, stdio streams, shell parsing, IPC, signal handling.
  • InfinyOn · Software Engineer · Mar 2024 - Nov 2025 · remote
    • 300% throughput improvement in the Fluvio producer through profiling and optimization.
    • Mirroring: real-time data replication across Fluvio clusters for disaster recovery and multi-region setups.
    • Rustls as an alternative to OpenSSL, and the migration from async-std to Tokio.
    • Enterprise features in InfinyOn Cloud: organization management and multi-tenancy.
    • Deadlocks and memory leaks in production, found and fixed.
  • Marigold · Software Engineer · Oct 2021 - Mar 2024 · remote
